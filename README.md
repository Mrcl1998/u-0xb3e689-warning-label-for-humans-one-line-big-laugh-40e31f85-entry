# Warning Label for Humans: One Line, Big Laugh

Entry for the make.fun bounty
[u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85)
— the safety warning label that should come printed on every human being,
at most 160 characters, funny first and plausible second.

## The entry (79 characters, one line)

> WARNING: Will say "I'm fine" while visibly on fire. Offer snacks, not advice.

## How it runs

`main.py` (pure Python standard library, no dependencies) writes the line
above to `/output/entry.txt` with no trailing newline and chmods the file
`0o644` so the grader's reader uid can read it. It never chmods the
`/output` directory itself.
